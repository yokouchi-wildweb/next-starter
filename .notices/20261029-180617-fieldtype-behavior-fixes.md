Date / number detection is unchanged. `getFieldTypes` / `convertRecordTypes` are now exported (for unit tests). (3) `isCheckboxArray(fieldConfig)` (src/components/Form/Field/Configured/inputResolver.tsx, same name and export): true for checkbox + `array` or `stringArray` (before: `array` only), the same answer as `isCheckGroupFieldType` that already decides the CheckGroup rendering.
why: Arrays have no meaningful sort order (the dictionary order of the first element), and `stringArray` was left out of the array checks when it was added. A behavior change gets its own checkpoint so a fork can follow or revert just this part.
