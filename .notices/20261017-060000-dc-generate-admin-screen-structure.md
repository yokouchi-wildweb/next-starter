why: upstream-request 20261017-141253 (TriQ). The generator was the only upstream code path still putting logic into `page.tsx`, so generated admin routes violated `ui_layers` while core routes complied, and a fork that wanted to customise one generated admin page had to fork page.tsx and lose regeneration. With write-once page.tsx + regenerable `_screen/` a fork can point page.tsx at its own `_components/<Name>Screen.tsx` while `dc:generate` keeps updating the default screen. Shared loaders (instead of per-domain generated loaders, which TriQ offered as an alternative) avoid N×3 generated files and collisions with the per-domain `loaders/README.md` listing rule.
