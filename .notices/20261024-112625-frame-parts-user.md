A menu item (`type: "menu"`, key, label, icon, optional menuTitle, `menu: { key, label, href, icon? }[]`, optional badge) opens an upward action menu (Overlays ActionPopover) and is never the current item. The item types (BottomNavItem, BottomNavLinkItem, BottomNavMenuItem, BottomNavMenuAction) are now defined in src/config/ui/user-bottom-menu.config.ts; upstream only replaced its import line with the type block. src/app/(user)/_layout/BottomNav/types.ts re-exports them and adds `isBottomNavMenuItem`. (3) Layout/Main takes `verticalAlign?: "center" | "start"` (default "center" = the current vertical centering; "start" = top-aligned), also through UserPage. (4) The default width of UserPage (non-fill) comes from the new value USER_PAGE_CONTAINER_TYPE in src/config/ui/user-layout.config.ts (default "contentShell", the same as before). (5) Old-path references left inside upstream (Header internal imports, file header comments) now use the new paths. The rendered DOM without the new props is unchanged (ids and classes included; fixed by test:user-layout).
