# 1 行 = <glob>  # <理由>。ここに無い書く場所は、どれかの上流の core のファイルか札の paths に当たること
# 足すのは決まりを書く物が本当に無い場所だけ(決まりがあるなら core のファイルの paths を広げる) | 新しく作った置き場だけに当たる 1 行は、置き場を作ったのと同じコミットで足してよい(窓口を通さない、core/design.md authoring)
