# shortcuts
> whole message = keyword only → run it | not one line → make it a skill

short|ショート|短く: restate previous answer, conclusion first, ≤5 bullets, paths only if actionable, no new work
1by1|ワンバイワン: go through the pending items one per message: questions, a tangled situation, a list of facts | order: most blocking or most foundational first | each starts with (k/N) and is self-contained (context + the point; a question adds options + recommendation) | plain text, no AskUserQuestion | next item only after the user replies
bullets|箇条書き|バレット: restate the whole previous answer as bullets (keep every point, unlike short) | each item = one point, as terse as possible, plain words | nest only when it clarifies structure | short captions (bold label / heading) allowed | no new work
