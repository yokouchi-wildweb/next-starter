# docs/journal/ — 日付付き記録の置き場

`.claude/rules/project.md` と `CLAUDE.md` に**書いてはいけない**種類の記録を置くディレクトリです。ここは自動ロードされないため、どれだけ書いてもセッションのコンテキストを消費しません。

## 置くもの

- インシデントの経緯(原因調査の過程、切り分け、最終的な原因)
- 検証結果(実機確認、Playwright での確認内容、件数の前後比較)
- 決定の経緯(検討した選択肢、見送った理由、いつ誰の指摘で方針が変わったか)
- 作業ログ(段階的な再設計の各ステップで何をしたか)
- ユーザーの「記録して」「残しておいて」に対する受け皿

## 置かないもの

- 恒常ルール・判断基準 → `.claude/rules/project.md`(`scope` 節の基準に従い 1 行に蒸留)
- 機能の仕様・使い方 → コード隣の README.md
- upstream の core 部品に関する教訓 → `/upreq` で上流へ

## ファイル名

`<YYYY-MM-DD>-<slug>.md`。1 件 1 ファイル。追記で育てず、新しい出来事は新しいファイルにする。

## 蒸留のルール

記録からフォーク固有の恒常ルールが抽出できる場合は、ルール 1 行だけを `project.md` の `dev_rules` に書き、本文はここに残す。project.md 側からは `ref: docs/journal/<file>` で参照できる。
