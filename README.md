# Next.js スターターテンプレート

---

## 🔷 プロジェクト概要

> このプロジェクトは最上流のアップストリームです

このリポジトリは、汎用的な Next.js アプリ基盤として提供しているテンプレートです。
初期状態では架空ドメインのサンプルが同梱されており、
不要な部分を差し替えることで多様なサービスへ迅速に転用できます。

**このリポジトリをフォークして新規プロジェクトを立ち上げる場合**は、下記の手順に従ってください。clone 後に `/fork-init` スキルを実行すると、このセクションを含むフォーク固有ファイルの書き換えまで自動で行われます。

➡️ **[新規プロジェクトの立ち上げ: フォークからデプロイまで](docs/how-to/initial-setup/新規プロジェクトの立ち上げ_フォークからデプロイまで.md)**
